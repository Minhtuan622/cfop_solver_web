# Kết quả kiểm tra tương tác

- Cube 3D hiển thị state thật và các điều khiển zoom/reset ở cả desktop lẫn mobile.
- Trang luyện Last Layer hiển thị CubeNet của state được tạo bằng chuỗi setup nghịch đảo từ database OLL/PLL; timer case chỉ bắt đầu khi bấm nút Start timer.
- Trang `/history` hiển thị trạng thái trống đúng khi chưa có lượt giải thực tế.
- Với lời giải mẫu đã tạo, timer full solve hiển thị thông báo rằng bấm Stop sẽ lưu một lượt vào Lịch sử. Dữ liệu kiểm thử nếu được tạo sẽ được xóa sau khi xác minh.
