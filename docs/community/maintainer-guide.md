# Hướng dẫn maintainer

- Giữ `main` ở trạng thái build được và chỉ merge PR đã có review/test phù hợp.
- Cập nhật tài liệu trong `docs/`, không tạo file Markdown rải rác ở root.
- Với thay đổi user-facing, cập nhật README hoặc tài liệu liên quan và cả bản dịch nếu cần.
- Khi phát hành, ghi rõ commit, thay đổi chính và kết quả kiểm thử.
- Không đưa secret, dữ liệu production hoặc log chứa thông tin cá nhân vào repository.
